CP Sync privacy policy

Effective date: October 9, 2026. Applies to CP Schedule & Git-Sync Ecosystem version 1.3.0.

CP Sync helps you track programming contests, add them to Google Calendar, back up accepted solutions to your GitHub repository, and keep problem notes and review lists. The project is maintained through its GitHub repository.

Information the extension uses

  • Programming platform pages: On supported LeetCode, Codeforces, AtCoder, CodeChef and CSES pages, the extension reads problem details, submission verdicts, your account identifier where needed to check ownership, and solution source associated with accepted submissions. LeetCode and CodeChef capture the editor contents when you submit, then wait for an accepted result before queueing a backup. CSES sheet import reads green accepted indicators and your own available submission sources after you start the import. These features use your existing platform session; CP Sync does not request your platform password.
  • GitHub: The extension uses the access token you supply or obtain through optional device sign-in, the repositories you can access, and your chosen repository and upload settings. It sends solution source, filenames, commit messages and optional problem metadata directly to GitHub. Metadata can include your saved problem notes. A public repository makes uploaded files public.
  • Google Calendar: After you authorize access, the extension reads calendar names and access levels so you can select a writable calendar. It reads event details to identify its own events, creates or updates contest events and their reminders, and can create a dedicated contest calendar. When you use the removal control, it deletes events it identifies as created by CP Sync in calendars it previously used. Unrelated events are not intentionally modified.
  • Your entries and settings: Notes, problem links, tags, review dates, solved states, attendance selections, import selections, repository choices, platform filters, reminder preferences and connection settings are stored to provide the features you choose.

Where information is stored and sent

Pending solution source, notes, review records, import batches, backup history and activity are stored in the extension's local browser storage or IndexedDB. GitHub tokens and manually supplied Google tokens are stored locally, without application-level encryption. Chrome manages Google sign-in tokens through its identity API. Settings such as repository choices and preferences use Chrome storage sync and may be synchronized by Chrome when your browser account has sync enabled. Pending sources and notes are not synchronized through Chrome storage sync. Legacy token preferences are removed from sync storage when settings are saved.

The contest-feed backend receives requests for contest schedules. The current extension does not send solution source, notes, GitHub tokens or Google tokens to this backend. The server and its hosting provider can receive ordinary request metadata, such as IP address and request time, and may retain operational logs according to their configuration. The developer does not control Chrome, GitHub, Google, programming-platform or hosting-provider retention policies. Choosing a different backend sends schedule requests to that provider.

The extension contacts supported programming platforms to retrieve contest, submission and source information. Google and GitHub receive requests necessary for the integrations you enable. GitHub Pages hosts this policy and may receive ordinary website request metadata when you visit it.

CP Sync contains no advertising or analytics SDK. It does not sell personal data or use Google user data for advertising. It does not collect general browsing history; content scripts operate on supported programming-platform sites for the features described above. It does not send your notes or solution source to an AI service.

CP Sync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Completed backup source is removed from the local queue after successful completion. Successful backup history is retained for up to 90 days and activity for up to 180 days, with cleanup performed while Chrome runs. Pending or failed backups remain until completed or removed. Notes and review entries remain until you delete them. Import data remains until processed or removed. Contest caches, connection settings and account-specific deduplication markers remain locally while the extension is installed.

You can delete notes, review entries and removable backup/import records through the extension, and remove its calendar events using Settings. Disconnecting an integration removes the saved connection credentials and pauses its automation; it does not delete existing GitHub commits, calendar events or all locally saved records. You can additionally revoke authorization through Google account security settings or GitHub token/application settings. Uninstalling the extension removes its local browser data. Browser-synced settings and third-party copies may require removal through those services. Deleting a GitHub file does not erase its earlier commits; manage repository history through GitHub if needed.

Your choices and security

You can pause automatic backup and calendar sync, disable on-page notes, disable metadata uploads, choose a private repository, and use contest mode to hold contest backups. Use the minimum GitHub access needed and protect access to your device. No storage or transmission system can guarantee complete security.

Changes and contact

Material changes will be reflected in this policy and the extension release notes. For privacy questions or deletion assistance, contact the maintainer through the repository. Do not post tokens, private code, personal notes or other sensitive information in public issues.
